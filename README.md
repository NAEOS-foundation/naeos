# NAEOS — Nusantara Engineering & Architecture Operating System

Specify Once. Build Anywhere.

Summary
NAEOS is a declarative engineering platform that converts formal specifications into code, artifacts, and AI contexts for multi-language generation, validation, and automation.

Quick Start
```bash
# clone & build
git clone https://github.com/NAEOS-foundation/naeos.git
cd naeos
go build ./cmd/naeos/
./naeos --help
```
