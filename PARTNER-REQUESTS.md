# NAEOS Partner Requests

These are small, optional requests for technical collaboration. They are not funding or sponsorship requests. Each request is subject to eligibility, approval, security review, and a mutually agreed scope. No cash payment or resource allocation is assumed.

## Cloud Infrastructure Pilot

**Request:** Limited cloud credits or infrastructure access, where available.

**NAEOS provides:** A reference architecture, integration work, technical documentation, and an open-source demo.

**Pilot duration:** Two to four weeks.

**Starting evidence:** Cloud resource types, provider adapters, Terraform export, and cloud CLI workflows are documented in [docs/NES-018-Cloud.md](docs/NES-018-Cloud.md) and the implementation.

## AI API Pilot

**Request:** Limited API access or developer credits, if offered by the partner program.

**NAEOS provides:** An integration example, an engineering workflow demo, and documentation.

**Pilot duration:** Two to four weeks.

**Scope:** Test an AI provider in the existing AI enrichment, compiler, context, or MCP workflow without implying exclusivity or endorsement.

## Academic Collaboration

**Request:** Student or researcher participation, benchmark work, or architecture review.

**NAEOS provides:** A public Apache-2.0 project, a research environment based on repository artifacts, and contributor recognition subject to project rules.

**Pilot duration:** Two to four weeks for an initial study or benchmark plan.

## Developer Community

**Request:** A community presentation, newsletter mention, technical workshop, or contributor recruitment opportunity.

**NAEOS provides:** Technical speakers or content, workshop material, and an open-source project for experimentation.

**Pilot duration:** One event or content cycle, followed by feedback review.

## Integration Pilot

**Request:** A narrow integration with an API, developer tool, plugin, profile, adapter, or workflow.

**NAEOS provides:** Maintainer coordination, a documented integration path, tests where applicable, and a reproducible example.

**Pilot duration:** Two to four weeks.

See the detailed pilot templates in [docs/partners/pilots/](docs/partners/pilots/).
