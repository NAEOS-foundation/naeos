# Launch Support List — D-4 to D-2

Private list of people who will upvote + comment on launch day. Do **not**
share publicly before the launch. Add anyone who has tried NAEOS, contributed,
or is enthusiastic about spec-driven engineering.

## How to use

1. Add rows for every supporter (Discord / X / LinkedIn / email / signal).
2. Send each the teaser below (D-4 to D-2) — personal messages only, no bulk.
3. On D-1, send each the exact launch link + time ("upvote + comment if you can").
4. Track status in the **Status** column: `teased`, `briefed`, `upvoted`, `commented`.

## Tracker tips

- Aim for 30–100 supporters for a strong dev-tool launch.
- Segment: (a) certain upvoters, (b) likely upvoters, (c) will comment.
- The commenters matter as much as upvoters — encourage honest feedback.
- Never send the same message verbatim to everyone; personalize the first line.
