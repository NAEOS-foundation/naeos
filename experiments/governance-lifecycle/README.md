# NAEOS Governance Lifecycle Experiment v1

## Thesis

> **The agent's claim is not the evidence.**

This experiment is the missing end-to-end proof layer identified during the NAEOS repository audit.

It demonstrates the lifecycle:

`AGENT INTENT → POLICY DECISION → AUTHORIZED ACTION → EXECUTION → OBSERVATION → EVIDENCE → INDEPENDENT VERIFICATION`

It deliberately does **not** use a live LLM or network service. The experiment isolates governance semantics using real NAEOS components:

- `internal/governance/control` for deterministic authorization;
- `internal/evidence` for append-only, hash-chained evidence;
- `internal/verification` for independent evidence, artifact, approval, and policy-freshness checks.

## Run

From the repository root:

```bash
go run ./experiments/governance-lifecycle
```

Exit code `0` means every lifecycle assertion passed. Exit code `2` means an experiment assertion failed.

The program emits machine-readable JSON so the same run can be consumed by CI, documentation, or a demo UI.

## Scenarios

| Scenario | What it proves |
|---|---|
| Complete lifecycle | A permitted action can be traced from intent through observation and independent verification. |
| Agent claim vs observation | An agent-reported success is not proof that the side effect happened. |
| Artifact mutation after approval | Approval is bound to an exact artifact hash, not a mutable filename. |
| Stale authorization replay | An authorization issued under an old policy version does not automatically survive a policy change. |

## Non-goals

This is not a production penetration test and does not claim that NAEOS is secure. Execution and observation are deterministic simulators because the purpose is to test the governance boundary itself.

## Reproducibility

The scenarios are fixed, local, and network-independent. Re-running the command exercises the same governance and verification paths. Timestamps are generated by the underlying evidence/verification components and are not part of the scenario oracle.

## Expected discussion

The useful question after running this experiment is not "did the AI follow the instructions?"

It is:

> **Can NAEOS independently establish what was authorized, what actually happened, and whether the resulting evidence still verifies?**

That is the boundary this experiment is designed to make visible.
