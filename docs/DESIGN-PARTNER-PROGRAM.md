# NAEOS Founding Design Partner Program

## Purpose

The Founding Design Partner Program validates NAEOS against real engineering workflows while keeping the pilot bounded, measurable and safe.

## Offer

**Duration:** 30–45 days  
**Scope:** 1 engineering team, 1–3 repositories, 1 bounded AI-assisted workflow.

### NAEOS provides

- architecture and workflow assessment
- installation/integration assistance
- policy mapping
- AI-agent integration guidance
- GitHub/CI integration where applicable
- weekly technical sessions
- policy configuration
- evidence review
- direct engineering access
- roadmap feedback channel

### Partner provides

- a bounded engineering workflow
- technical stakeholder access
- baseline metrics
- feedback during the pilot
- authorization for any required repository/infrastructure access
- optional approval for anonymized public case study

No migration away from existing AI coding tools is required.

## Pilot workflow

Baseline → Connect NAEOS → Define policy boundary → Run controlled workflow → Verify outcomes → Collect evidence → Business/technical review

## Acceptance criteria

A pilot should define measurable criteria before execution.

Examples:
- policy decisions are observable
- unauthorized actions are denied at the intended control boundary
- authorized actions execute within the agreed scope
- evidence links intent, authorization, execution and observation
- verification results are independently inspectable
- existing engineering workflow remains usable

Do not claim production safety or compliance merely because a pilot succeeds.

## Baseline metrics

Select metrics appropriate to the workflow:
- PR cycle time
- review/rework
- architecture violations
- policy violations
- agent interventions
- manual approvals
- context preparation effort
- verification outcomes
- evidence completeness

## Commercial path

Successful pilots may transition to an annual enterprise agreement.

Initial pricing hypothesis:
- paid pilot: $10k–$20k / 6–8 weeks
- Team: $25–50 / engineer / month
- Business: $75–125 / engineer / month
- Enterprise: custom

Pricing is a hypothesis until validated with design partners.

## Pilot principles

1. Start with one bounded workflow.
2. Keep authorization explicit.
3. Revalidate before consequential external actions.
4. Separate proposal, policy decision, execution and observation.
5. Preserve durable evidence.
6. Fail closed on unsupported policy/schema/version conditions.
7. Do not treat agent output as proof of execution.
8. Do not publish partner information without approval.

## Design partner success review

At the end of the pilot:
- review baseline vs observed results
- document failures and limitations
- identify production blockers
- decide whether to expand scope
- decide whether a paid deployment is justified
- record evidence and open technical gaps
