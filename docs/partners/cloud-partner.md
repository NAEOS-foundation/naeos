# Cloud Partner Brief

## 1. Partner objective

Validate a small NAEOS cloud workflow or reference architecture without assuming credits or commercial support.

## 2. Current NAEOS capability relevant to the partnership

NAEOS documents cloud resource models, provider adapters, Terraform export, cloud planning, and cloud CLI workflows. Confirm the exact provider and resource scope before proposing work.

## 3. Proposed pilot

Use a minimal specification to plan or export a small set of cloud resources. Keep deployment, data, credentials, and production use out of scope unless separately approved.

## 4. Partner contribution

Potential contribution: limited sandbox access, credits where available, provider guidance, or technical review, subject to eligibility and approval.

## 5. NAEOS contribution

NAEOS can provide a reference specification, adapter changes where accepted, Terraform output review, documentation, and an open-source example.

## 6. Expected technical output

One reproducible cloud example, documented resource mapping, tests, and a review of limitations.

## 7. Success criteria

The example parses, validates, produces the expected plan or export, and documents provider-specific constraints without exposing secrets.

## 8. Timeline

Target two to four weeks for a sandbox pilot.

## 9. No-cash collaboration model

No cloud credits or payment are guaranteed. Any access is optional, time-limited, and mutually agreed.

## 10. Next step

Agree on provider, region, resource types, access controls, cost ceiling, data policy, and acceptance test.
