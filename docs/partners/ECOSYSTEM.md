# NAEOS Partner Ecosystem

The ecosystem model starts with a small technical contribution and produces a reproducible integration or research result. It does not assume funding, credits, or a commercial outcome.

```mermaid
flowchart TD
    N[NAEOS] --> T[Technology]
    N --> R[Research]
    N --> C[Community]
    T --> CL[Cloud]
    T --> AI[AI]
    T --> TOOLS[Developer tools]
    R --> U[Universities]
    R --> LABS[Research labs]
    C --> DEV[Developers]
    C --> OSS[Open-source communities]
    CL --> P[Pilot users]
    AI --> P
    TOOLS --> P
    U --> P
    LABS --> P
    DEV --> P
    OSS --> P
    P --> W[Real workloads]
    W --> CS[Case studies with approval]
    CS --> E[More ecosystem collaboration]
```
