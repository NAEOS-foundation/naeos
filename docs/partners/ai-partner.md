# AI Partner Brief

## 1. Partner objective

Test a bounded AI provider or model integration in an existing NAEOS engineering workflow.

## 2. Current NAEOS capability relevant to the partnership

NAEOS includes AI provider workflows, AI enrichment and compiler paths, context bundles, MCP integration, and output adapters for multiple AI tools. Provider support and behavior must be verified for the proposed use case.

## 3. Proposed pilot

Run a small specification through an AI context, enrichment, or compiler workflow using a non-sensitive test project.

## 4. Partner contribution

Potential contribution: limited API access, developer credits where available, model documentation, sandbox support, or technical review.

## 5. NAEOS contribution

NAEOS can provide an integration example, test fixtures, engineering workflow documentation, and a reproducible demo without implying endorsement.

## 6. Expected technical output

A documented provider configuration, example run, output comparison, and known limitations.

## 7. Success criteria

The workflow is reproducible, handles provider errors, protects secrets and sensitive data, and records which behavior is verified.

## 8. Timeline

Target two to four weeks for a non-sensitive pilot.

## 9. No-cash collaboration model

No API credits, model access, or payment is guaranteed. Access remains subject to the provider's eligibility and approval rules.

## 10. Next step

Agree on provider, model, test data, rate limits, security review, and public-claim approval.
