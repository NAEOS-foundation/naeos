# Community Pilot

## Pilot Objective
Help a defined developer community try one NAEOS workflow and return actionable feedback.

## Problem
What audience problem or learning goal will the session address?

## Proposed Integration
Deliver one workshop, presentation, newsletter feature, office hour, or contributor session using a verified example.

## Partner Contribution
Potential distribution, event coordination, moderation, feedback, or contributor recruitment.

## NAEOS Contribution
Speaker or technical content, workshop material, examples, and maintainer follow-up.

## Deliverables
Agenda, materials, reproducible example, feedback summary, and follow-up issues.

## Technical Acceptance Criteria
Materials run as documented, claims match repository evidence, and feedback is recorded without personal data beyond what is authorized.

## Timeline
One event or content cycle within two to four weeks.

## Publicity / Case Study
Recording, logos, quotes, and participant metrics require permission.

## Exit Criteria
The session is delivered, feedback is reviewed, and any next step has an owner.
