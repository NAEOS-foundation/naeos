# Integration Pilot

## Pilot Objective
Build and verify one narrow integration between NAEOS and a partner API, tool, plugin, profile, adapter, or workflow.

## Problem
State the integration friction and the developer outcome being tested.

## Proposed Integration
Define the interface, fixture, data flow, failure behavior, and explicit out-of-scope work.

## Partner Contribution
Potential API or sandbox access, interface documentation, test account, technical contact, or review.

## NAEOS Contribution
Maintainer coordination, implementation where accepted, tests, documentation, and a reproducible example.

## Deliverables
Integration code or configuration, example, tests, documentation, and known limitations.

## Technical Acceptance Criteria
The agreed interface works on the fixture, errors are handled, tests are repeatable, and licensing/security requirements are met.

## Timeline
Two to four weeks.

## Publicity / Case Study
Only approved technical claims and partner references may be published.

## Exit Criteria
The integration meets acceptance criteria or has a documented decision to revise or stop.
