# Cloud Pilot

## Pilot Objective
Validate one bounded NAEOS cloud planning or export workflow.

## Problem
Which resource modeling, provider mapping, or reproducibility question needs evidence?

## Proposed Integration
Use a minimal specification and the documented cloud adapter or Terraform export path. Keep deployment and production data out of scope unless approved.

## Partner Contribution
Potential sandbox access, provider guidance, credits if eligible, or technical review. Nothing is guaranteed.

## NAEOS Contribution
Reference specification, integration work, documentation, and an open-source example.

## Deliverables
Specification, generated plan or export, tests, run notes, and limitations.

## Technical Acceptance Criteria
The fixture parses and validates, the expected resources are represented, output is reproducible, and no credentials are committed.

## Timeline
Two to four weeks.

## Publicity / Case Study
Only with partner approval. Do not publish provider names, metrics, or infrastructure details without permission.

## Exit Criteria
Acceptance criteria pass, limitations are documented, and both parties decide whether to stop, revise, or extend.
