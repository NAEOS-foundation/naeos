## naeos sign sign

Sign an artifact file

```
naeos sign sign <artifact-path> [flags]
```

### Options

```
  -h, --help                   help for sign
      --key string             path to private key file (JSON)
  -o, --output string          output signature path (default: <artifact>.sig.json)
      --output-format string   output format: file or json (default "file")
      --signer string          signer identity
```
