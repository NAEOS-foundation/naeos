## naeos schema list

List available schema versions in the registry

```
naeos schema list [flags]
```

### Options

```
  -h, --help              help for list
  -o, --output string     output format: text, json (default "text")
      --registry string   remote schema registry URL to show alongside local entries (default "https://registry.naeos.dev/schemaregistry/latest.json")
```
