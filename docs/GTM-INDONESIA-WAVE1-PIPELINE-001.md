## Qualification gate

Do not call an account a pilot candidate until discovery establishes:

1. A real AI-assisted engineering workflow exists.
2. The agent has meaningful access or a consequential proposed action.
3. There is a concrete authorization/control boundary to examine.
4. Evidence of execution or verification matters to the team.
5. The workflow can be bounded without replacing the existing engineering stack.
6. The partner can identify a technical owner.
7. Success criteria can be observed within a short pilot.

## Operating rule

Do not optimize for the number of conversations. Optimize for learning whether a concrete control gap exists and whether NAEOS can test it without creating unnecessary engineering friction.
