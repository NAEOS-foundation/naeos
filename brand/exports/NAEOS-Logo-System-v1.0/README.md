# NAEOS Logo System v1.0

Status: Historical derivative package. Its variants were derived from the approved Candidate v1.0 geometry and predate registration of Logo Master v2.0.0. Do not use these variants as current canonical masters without revalidation.

Package contents include gradient, flat, monochrome, app-icon, favicon, and contact-sheet exports. The historical `naeos-primary-symbol-master-v1.svg` must remain clearly labeled as historical. Binary exports are pending upload.

Color references recorded by the source package: Obsidian `#0B0F19`, Signal Blue `#2563FF`, Ion Blue `#60A5FA`, Mist `#E5E7EB`, Cloud White `#FFFFFF`.
