## NAEOS 3.5.0

Declarative platform engineering system — transform specifications into validated, multi-language project structures.

### Installation

```bash
curl -fsSL https://naeos.dev/install.sh | sh
```

Or with Go:

```bash
go install github.com/NAEOS-foundation/naeos/cmd/naeos@v3.5.0
```

### What's New in v3.1.0

- **Pipeline caching** — `naeos run --cache-dir <dir>` caches intermediate stage results; rebuilds reuse cached output for faster iteration
- **Pipeline profiling on `naeos run`** — `--profile`/`--profile-out` capture per-stage timing, `--pprof` exposes a pprof HTTP server for live heap/CPU inspection
- **Architecture patterns** — monolithic, microservices, and serverless patterns in the NEIR model
- **WASM plugin hardening** — plugin host requires exported metadata symbols; expanded WASM sandbox support
