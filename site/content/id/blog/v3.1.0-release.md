Kami dengan bangga mengumumkan rilis NAEOS v3.1.0! Rilis ini berfokus pada siklus iterasi yang lebih cepat dan pengerasan platform.

## Yang Baru

### Pipeline Caching pada `naeos run`

`naeos run --cache-dir <dir>` meng-cache hasil stage perantara berdasarkan hash NEIR (SHA256). Build ulang dengan input yang tidak berubah menggunakan output cache alih-alih regenerate dari awal. Ini memangkas waktu pengembangan iteratif secara signifikan — terutama untuk spec besar dengan banyak modul.

```bash
naeos run --input-file spec.yaml --cache-dir .naeos-cache
```

### Profiling Tingkat Run

`naeos run --profile` merekam timing per-stage untuk pipeline 7 stage (validate → build_graph → policy_eval → schedule → generate → review → write_artifacts). `--profile-out <file>` menulis JSON profile, dan `--pprof <addr>` memulai server HTTP pprof untuk inspeksi heap dan CPU secara live.

```bash
naeos run --input-file spec.yaml --profile --profile-out profile.json
naeos run --input-file spec.yaml --pprof localhost:6060
```

### Pola Arsitektur

Pola monolitik, microservices, dan serverless kini menjadi first-class dalam model NEIR. Pola arsitektur memengaruhi code generation, manifest deployment, dan bundle konteks AI.

```yaml
architecture:
  pattern: microservices
  description: Event-driven microservices with gRPC inter-service communication
```

### Pengerasan Plugin WASM

Plugin host kini mewajibkan simbol metadata yang diekspor (`PluginName`, `PluginVersion`, `PluginDescription`) dan hadir dengan dukungan sandbox WASM yang diperluas. Plugin berjalan di memori terisolasi dengan syscall yang terkontrol, membuat marketplace lebih aman untuk ekstensi pihak ketiga.
