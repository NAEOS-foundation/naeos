Kami dengan bangga mengumumkan rilis NAEOS v3.0.0! Rilis besar ini berfokus pada pengalaman pengembang, observabilitas, dan perangkat komunitas.

## Yang Baru

- **Pipeline Profiling & Analisis Memori** — `PipelineProfile` mencatat waktu per tahap, dan `MemProfiler` menyediakan heap snapshot, analisis tekanan GC, dan deteksi kebocoran. Jalankan `naeos build --profile` atau `naeos profile run`.

- **Stage Caching** — `StageCache` berbasis file untuk tahap `schedule` dan `generate`, dikunci dengan hash NEIR (SHA256). Build berikutnya otomatis menggunakan hasil cache.

- **LSP Server Sadar-NEIR** — Implementasi Language Server Protocol lengkap dengan autocomplete kontekstual, diagnostik real time, hover docs, go-to-definition, document symbols, dan code actions untuk file `.naeos.yaml`.

- **Build Terdistribusi Nyata** — `naeos build --distributed --workers N` menjalankan pipeline nyata per modul dan mengagregasi hasil di banyak worker.

- **Generasi Ekstensi VS Code** — `naeos dx vscode-gen` menghasilkan ekstensi VS Code lengkap dengan syntax highlighting, klien LSP, dan perintah.

- **Contoh Plugin Resmi** — `examples/plugins/` menyediakan tiga plugin referensi (`hello`, `spec-lint`, `artifact-stats`) yang menunjukkan Plugin SDK.

- **Starter Template Resmi** — `examples/templates/microservices-go/` adalah starter Go REST + event-driven lengkap, terhubung ke registry template.

- **266 Tes CLI Baru** — Coverage perintah CLI naik dari 45,5% ke 66,2%; coverage keseluruhan kini 81,5% dengan gerbang CI yang ketat.

- **Whitepaper Resmi** — Whitepaper NAEOS diterbitkan dalam Bahasa Inggris dan Indonesia, dengan build PDF di CI.
