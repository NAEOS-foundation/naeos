Kami dengan bangga mengumumkan rilis NAEOS v2.2.0! Rilis ini menghadirkan kemampuan baru yang signifikan pada platform.

## Yang Baru

- **Integrasi Supabase** — Dukungan penuh untuk Supabase sebagai backend database. Perintah `naeos supabase` untuk manajemen pengguna, deployment Edge Function, dan operasi penyimpanan.

- **Workspace Multi-Tenant** — Workspace terisolasi dengan konfigurasi per-tenant, kuota sumber daya, dan jejak audit. Setiap workspace menjaga riwayat spesifikasi, status deployment, dan keanggotaan tim sendiri.

- **API Schema Registry** — REST API untuk mempublikasikan, membuat versi, dan menemukan skema NEIR. Memungkinkan resolusi skema dinamis di seluruh tim terdistribusi.

- **CLI Ekspor Kepatuhan** — Ekspor log audit, riwayat deployment, dan laporan tata kelola sebagai JSON, CSV, atau PDF untuk kebutuhan kepatuhan dan regulasi.

- **44 Tes Unit Baru** — Cakupan pengujian yang diperluas di seluruh kompiler, adaptor database, dan penyedia autentikasi.
