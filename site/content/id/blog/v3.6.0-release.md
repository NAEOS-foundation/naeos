Kami dengan senang mengumumkan rilis NAEOS v3.6.0. Rilis ini menyatukan control plane untuk engineering berbasis agent — otorisasi, approval, dan evidence anti-tamper sebagai building block yang dapat dipakai ulang — serta memperkuat supply chain untuk distribusi open source.

## Hal Baru

### Unified Control Plane

`internal/controlplane` menggeneralisasi alur otorisasi dan evidence yang pertama kali dibangun untuk demo investor menjadi inti yang dapat dipakai ulang:

- `PolicyStore` + `Evaluator` — keputusan deny / allow / require-approval dengan konteks lengkap
- `DecisionGateway` — mengikat eksekusi ke keputusan kanonikal
- `Ledger` — catatan keputusan dan eksekusi anti-tamper dengan filter evidence
- `ApprovalStore` dan `SessionVerifier`

Seluruhnya tercakup tes (approval, ledger, evaluator, gateway, verifier).

### Idempotency Message Queue

`internal/messagequeue` kini memiliki idempotency kelas satu: antarmuka `IdempotencyStore` dengan implementasi in-memory, idempotency key pada message, deteksi duplikat (`ErrDuplicateMessage`), statistik dedup, dan pembersihan berbasis TTL. Ini menjadi fondasi untuk durable job queue dan worker pipeline jaringan yang ada di roadmap.

### Attachment Database API

`naeos api` kini dapat menambahkan database saat `NAEOS_DB_DRIVER` / `NAEOS_DB_DATABASE` diatur (sqlite, postgres, mysql, mariadb), membuat tabel `pipeline_runs` dan menyimpan catatan run. `NAEOS_ENCRYPTION_KEY` + `NAEOS_API_ADMIN_USER` meng-seed user admin RBAC untuk rute yang dilindungi JWT.

### Integrasi API dan Dashboard Demo Investor

API demo mengekspos alur otorisasi, approval, evidence, dan verifikasi melalui HTTP; execution gate kini menyelesaikan resolusi terhadap control plane kanonikal (fail-closed) dengan persistensi ledger anti-tamper.

### Penguatan Supply-Chain

- Dependabot untuk Go dan npm, GitHub Actions dengan SHA-pinned
- Scan gitleaks pada setiap push
- `NOTICE` + SBOM disertakan di setiap arsip rilis
- Penegakan header SPDX (direktori hasil generasi dikecualikan)
- Penegakan DCO pada push dan pull request

## Cara Mendapatkannya

```bash
curl -fsSL https://naeos.dev/install.sh | sh
```

Atau dengan Go:

```bash
go install github.com/NAEOS-foundation/naeos/cmd/naeos@v3.6.0
```

Seluruh aset rilis ditandatangani dengan kunci rilis Ed25519 NAEOS. Verifikasi aset yang diunduh dengan:

```bash
naeos sign verify <artifact>.sig.json
```
