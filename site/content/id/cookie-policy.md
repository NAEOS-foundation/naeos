Kebijakan Cookie ini menjelaskan bagaimana situs web NAEOS (naeos.dev)
menggunakan cookie dan teknologi serupa.

## 1. Apa Itu Cookie?

Cookie adalah file teks kecil yang disimpan di perangkat Anda oleh browser.
Cookie membantu situs web mengingat preferensi Anda dan memahami bagaimana situs
digunakan.

## 2. Cookie yang Kami Gunakan

NAEOS **tidak menggunakan cookie pelacakan atau iklan**. Satu-satunya penyimpanan
lokal yang digunakan adalah flag yang mencatat pilihan persetujuan cookie Anda —
ini bukan cookie dan tidak mengandung data pribadi.

### Layanan pihak ketiga yang mungkin menetapkan cookie

| Layanan | Tujuan |
|---------|--------|
| GitHub | Dapat menetapkan cookie saat Anda mengunjungi halaman yang didukung GitHub (statistik, tautan repositori). Diatur oleh [kebijakan cookie GitHub](https://github.com/privacy) |
| Google Fonts | Menyajikan font; dapat menetapkan cookie seperti dijelaskan dalam [kebijakan cookie Google](https://policies.google.com/technologies/cookies) |
| Netlify | Hosting; dapat menetapkan cookie fungsional seperti dijelaskan dalam [kebijakan cookie Netlify](https://www.netlify.com/privacy/) |

## 3. Mengelola Cookie

Anda dapat mengontrol dan menghapus cookie di pengaturan browser Anda. Menolak
banner persetujuan cookie tidak memengaruhi fungsi inti situs web — situs
berfungsi tanpa cookie.
