_Terakhir diperbarui: 16 Agustus 2026_

Kebijakan Privasi ini menjelaskan informasi apa yang dikumpulkan oleh proyek
NAEOS, bagaimana data digunakan, dan pilihan yang Anda miliki. Kebijakan ini
mencakup alat CLI NAEOS, situs web (naeos.dev), dan komunitas Discord NAEOS.

## 1. Data yang Kami Kumpulkan

### Alat CLI NAEOS

NAEOS adalah alat baris perintah yang berjalan secara lokal di mesin Anda.
**Kami tidak mengumpulkan atau mengirimkan data apa pun dari penggunaan CLI.**
Tanpa telemetri, tanpa laporan kerusakan, tanpa analitik. Spesifikasi, proyek,
dan kode yang dihasilkan tidak pernah meninggalkan mesin Anda.

### Situs Web (naeos.dev)

Saat Anda mengunjungi situs web, kami dapat mengumpulkan:

- **Data penggunaan anonim** melalui analitik yang berfokus pada privasi (tanpa data pribadi)
- **Alamat email buletin** saat Anda berlangganan secara sukarela — disimpan
  dengan preferensi bahasa dan sumber langganan agar kami dapat mengirim
  pembaruan NAEOS
- **Data API GitHub** — saat Anda mengunjungi halaman yang menampilkan statistik
  GitHub (bintang, fork), browser Anda mengambil data dari API publik GitHub.
  Tidak ada data autentikasi yang dikumpulkan
- **Preferensi persetujuan cookie** — disimpan secara lokal di browser Anda
  (lihat [Kebijakan Cookie](/id/cookie-policy/))

### Komunitas Discord

Saat Anda bergabung dengan server Discord NAEOS, Discord memproses informasi
akun Anda (nama pengguna, avatar, peran, pesan) berdasarkan
[Kebijakan Privasi Discord](https://discord.com/privacy). Bot NAEOS hanya membaca
pesan channel yang diperlukan untuk memposting pengumuman dan menjalankan
perintahnya.

## 2. Data yang TIDAK Kami Kumpulkan

- NAEOS tidak mengumpulkan telemetri dari alat CLI
- NAEOS tidak melacak spesifikasi, proyek, atau kode yang dihasilkan
- NAEOS tidak menggunakan cookie untuk tujuan pelacakan (hanya flag penyimpanan
  lokal untuk persetujuan cookie)
- NAEOS tidak menjual atau menyewakan data pribadi Anda kepada siapa pun

| Layanan | Tujuan | Kebijakan |

## 4. Cara Kami Menggunakan Data Anda

Alamat email Anda (jika berlangganan) digunakan semata-mata untuk mengirim
pembaruan, rilis, dan pengumuman peluncuran NAEOS. Kami tidak membagikan email
Anda kepada pihak ketiga untuk pemasaran.

## 5. Penyimpanan Data

- Email buletin: disimpan hingga Anda berhenti berlangganan atau meminta penghapusan
- Analitik: diagregasi, dianonimkan, dan disimpan tanpa pengenal pribadi

## 6. Pilihan Anda

- **Buletin**: berhenti berlangganan melalui tautan di email mana pun, atau hubungi kami
- **Persetujuan cookie**: tolak melalui banner — situs berfungsi tanpa persetujuan
- **Akses/penghapusan**: minta penghapusan data Anda dengan menghubungi kami (Bagian 8)

## 7. Perlindungan Data (GDPR/CCPA)

Jika Anda berada di Uni Eropa/Inggris (GDPR) atau California (CCPA/CPRA), Anda
memiliki hak untuk mengakses, mengoreksi, menghapus, dan memindahkan data
pribadi Anda. Hubungi kami untuk menggunakan hak-hak tersebut. Kami memproses
data berdasarkan persetujuan Anda dan kepentingan sah (meningkatkan proyek dan
mengkomunikasikan pembaruan).

## 8. Kontak

Untuk pertanyaan terkait privasi, buka issue pada
[repositori GitHub NAEOS](https://github.com/NAEOS-foundation/naeos) atau hubungi
pemelihara di [bayu@naeos.dev](mailto:bayu@naeos.dev).
