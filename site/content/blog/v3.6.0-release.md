We're excited to announce the release of NAEOS v3.6.0. This release unifies the control plane for agent-driven engineering — authorization, approvals, and tamper-evident evidence as reusable building blocks — and hardens the supply chain for open-source distribution.

## What's New

### Unified Control Plane

`internal/controlplane` generalizes the authorization and evidence flows first built for the investor demo into a reusable core:

- `PolicyStore` + `Evaluator` — deny / allow / require-approval decisions with full context
- `DecisionGateway` — binds execution to canonical decisions
- `Ledger` — tamper-evident decision and execution records with evidence filters
- `ApprovalStore` and `SessionVerifier`

All fully covered by tests (approval, ledger, evaluator, gateway, verifier).

### Message Queue Idempotency

`internal/messagequeue` gains first-class idempotency: an `IdempotencyStore` interface with an in-memory implementation, idempotency keys on messages, duplicate detection (`ErrDuplicateMessage`), dedup stats, and TTL-based cleanup. This is the foundation for the durable job queue and networked worker pipeline on the roadmap.

### API Database Attachment

`naeos api` now attaches a database when `NAEOS_DB_DRIVER` / `NAEOS_DB_DATABASE` are set (sqlite, postgres, mysql, mariadb), creating the `pipeline_runs` table and persisting run records. `NAEOS_ENCRYPTION_KEY` + `NAEOS_API_ADMIN_USER` seed an admin RBAC user for JWT-protected routes.

### Investor Demo API + Dashboard Integration

The demo API exposes authorization, approval, evidence, and verification flows over HTTP; the execution gate now resolves against the canonical control plane (fail-closed) with tamper-evident ledger persistence.

### Supply-Chain Hardening

- Dependabot for Go and npm, SHA-pinned GitHub Actions
- gitleaks scans on push
- `NOTICE` + SBOM shipped in every release archive
- SPDX header enforcement (generated dirs excluded)
- DCO enforcement on push and pull requests

## Get It

```bash
curl -fsSL https://naeos.dev/install.sh | sh
```

Or with Go:

```bash
go install github.com/NAEOS-foundation/naeos/cmd/naeos@v3.6.0
```

All release assets are signed with the NAEOS Ed25519 release key. Verify any downloaded asset with:

```bash
naeos sign verify <artifact>.sig.json
```
