We're excited to announce the release of NAEOS v2.1.0! This release brings enterprise-grade features to the platform.

## What's New

### RBAC Bootstrapping

Role-based access control now initializes automatically on server start with three built-in roles: `admin`, `developer`, and `viewer`. Each role maps to specific route permissions, and custom roles can be created with inheritance chains.

```bash
naeos auth create-role devops \
  --parent developer --permission pipeline:run --deny spec:delete
```

### Multi-Tenant Workspaces

Isolated workspaces with per-tenant configuration, resource quotas, and audit trails. Each workspace maintains its own spec history, deployment state, and team membership. API endpoints: `GET/POST /api/v1/tenants`.

### Schema Registry API

REST API for publishing, versioning, and discovering NEIR schemas. Five endpoints for full lifecycle management:

```bash
naeos schema list
naeos schema publish --name my-schema --version 1.0.0
naeos schema get --name my-schema --version 1.0.0
```

### 5 Industry Profiles

New built-in profiles for common architectures: `edtech-platform`, `ecommerce-engine`, `iot-backend`, `media-streaming`, `blockchain-node`.

### Encryption at Rest

User store now supports transparent AES-256-GCM encryption via the `NAEOS_ENCRYPTION_KEY` environment variable. All user data is encrypted on disk.

### Compliance Export CLI

Export audit logs, deployment history, and governance reports as JSON or CSV:

```bash
naeos compliance export --audit-file ~/.naeos/audit.log --format json
```

### Security Hardening

- Path traversal validation for `$include{}`/`$import{}` directives
- Encrypted user store with AES-256-GCM
- Structured logging for error paths across 10+ locations
