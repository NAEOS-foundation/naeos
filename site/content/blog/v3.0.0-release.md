We're excited to announce the release of NAEOS v3.0.0! This is a major release focused on developer experience, observability, and community tooling.

## What's New

- **Pipeline Profiling & Memory Analysis** — `PipelineProfile` records timing per stage, and `MemProfiler` provides heap snapshots, GC pressure analysis, and leak detection. Run `naeos build --profile` or `naeos profile run`.

- **Stage Caching** — File-backed `StageCache` for the `schedule` and `generate` stages, keyed by NEIR hash (SHA256). Subsequent builds reuse cached results automatically.

- **NEIR-Aware LSP Server** — Full Language Server Protocol implementation with context-aware autocomplete, real-time diagnostics, hover docs, go-to-definition, document symbols, and code actions for `.naeos.yaml` files.

- **Distributed Real Builds** — `naeos build --distributed --workers N` runs the real pipeline per module and aggregates results across workers.

- **VS Code Extension Generation** — `naeos dx vscode-gen` generates a complete VS Code extension with syntax highlighting, LSP client, and commands.

- **Official Example Plugins** — `examples/plugins/` ships three reference plugins (`hello`, `spec-lint`, `artifact-stats`) showing the Plugin SDK in action.

- **Official Starter Template** — `examples/templates/microservices-go/` is a complete REST + event-driven Go starter, wired into the template registry.

- **266+ New CLI Tests** — CLI command coverage rose from 66.2% to 80.8%; overall coverage is now 86.9% with a hard CI gate.

- **Official Whitepaper** — The NAEOS whitepaper is published in English and Bahasa Indonesia, with PDF builds in CI.
