We're excited to announce the release of NAEOS v3.1.0! This release focuses on faster iteration loops and platform hardening.

## What's New

- **Pipeline Caching on `naeos run`** — `naeos run --cache-dir <dir>` caches intermediate stage results keyed by NEIR hash. Rebuilds with unchanged inputs reuse cached output instead of regenerating from scratch.

- **Run-Level Profiling** — `naeos run --profile` captures per-stage timing, `--profile-out <file>` writes the profile JSON, and `--pprof <addr>` starts a pprof HTTP server for live heap and CPU inspection.

- **Architecture Patterns** — monolithic, microservices, and serverless patterns are now first-class in the NEIR model.

- **WASM Plugin Hardening** — the plugin host requires exported metadata symbols and ships expanded WASM sandbox support.
